# PIE(중국) - Powernet Industrial Engineering (오프라인/중국용)

인터넷 연결 없이 동작하도록 만든 버전입니다. 구글 시트(GAS) 연동을 제거하고
부품 ST 누적 관리는 로컬 파일(.pie) 기반으로 대체했으며, MediaPipe(Pose) 모델도
이 폴더의 `mediapipe/pose/`에 내려받아 로컬에서 서빙합니다.

## 실행 방법 (권장)
1. 이 폴더에서 `PIE(중국).bat` 더블클릭
2. 자동으로 로컬 서버가 뜨고 브라우저가 열립니다 (인터넷 연결 불필요)
3. 프로그램을 종료하려면 뜬 명령창을 닫으면 됩니다

(주의) `PIE.html`을 더블클릭으로 직접 여는 것도 가능하지만, 그 경우 브라우저의
`file://` 보안 제한 때문에 Pose 비교(MediaPipe) 기능이 정상 동작하지 않을 수
있습니다. 반드시 `PIE(중국).bat`로 실행하세요.

### ⚠ 데이터는 "주소별"로 저장됩니다 (중요)
브라우저는 저장 데이터(부품 목록·표준시간·설정)를 **주소(포트)마다 따로** 보관합니다.
그래서 평소 쓰던 `http://127.0.0.1:8791` 이 아닌 다른 주소로 열리면, 데이터가
지워진 것처럼 **아무것도 안 보입니다**(실제로 지워진 것은 아님).
- 프로그램은 항상 **8791** 포트를 쓰도록 되어 있고, 이미 켜져 있으면 새 서버를
  띄우지 않고 그 창을 그대로 재사용합니다.
- 다른 주소로 열리면 화면 맨 위에 빨간 경고 띠와 **[표준 주소로 열기]** 버튼이 뜹니다.
- 8791을 다른 프로그램이 점유하면 실행 시 검은 창에 경고가 표시됩니다. 그 프로그램을
  끄고 PIE를 다시 실행하세요.

## ⚠ 프로그램을 두면 안 되는 위치
문서중앙화·클라우드 드라이브(**Cloudium**, OneDrive, 네트워크 드라이브)와 USB에서
**바로 실행하지 마세요.** 그런 드라이브는 실행 파일을 막습니다.

> `[cloudium] 디스크 드라이브에서 [.bat]와 같은 실행 파일의 동작은 지원하지 않습니다.`

이 오류는 프로그램 결함이 아니라 **폴더를 둔 위치** 문제입니다. 해결 순서:

1. 폴더를 `C:` 또는 `D:` 로컬 디스크(예: `D:\PIE`)로 옮기고 다시 실행
2. 그래도 막히면 — `PIE_local_server.ps1` 우클릭 → **PowerShell에서 실행** (`.bat`을 안 거침)
3. 설치기로 만든 **바탕화면 바로가기**도 `.bat`을 거치지 않고 `powershell.exe`를 직접 부릅니다
4. 최후 — `PIE.html` 더블클릭 (대부분 기능 정상, **Pose 비교만 동작하지 않음**)

## USB로 다른 PC에 옮길 때 (권장)
폴더를 통째로 복사하면 `.git`(파일 수천 개)·`BOM`(엑셀 잠금 파일) 때문에
"권한 필요 / 사용 중" 오류로 복사가 막힙니다. 대신:

1. `PIE_USB_묶기.bat` 더블클릭
2. 바탕화면에 `PIE_배포_YYYYMMDD.zip` (약 9MB) 이 생깁니다
3. **이 ZIP 하나만** USB로 끌어다 놓으세요
4. 받는 PC에서 압축을 풀고 `PIE(중국).bat` 실행

실행에 필요한 파일(PIE.html · 로컬 서버 · mediapipe 자산)과 가이드만 담기며,
BOM 폴더·작업 문서·`.git` 은 담기지 않습니다. 라이선스 키도 들어가지 않으니
따로 전달하세요.

## 설치(다른 PC에 배포할 때)
- 권장: `PIE_설치.bat` 실행 — 프로그램 전체(mediapipe 자산·로컬 서버 포함)가
  설치되고, 바탕화면/시작 메뉴 바로가기가 `PIE(중국).bat`(로컬 서버 실행)으로
  연결됩니다. Pose 기능까지 정상 동작하는 설치 방식입니다.
- 또는 이 폴더 전체를 그대로 복사한 뒤 `PIE(중국).bat`을 실행해도 됩니다.
- 제거: 시작 메뉴의 "PIE 제거" 또는 설치 폴더의 `PIE_제거.bat`
